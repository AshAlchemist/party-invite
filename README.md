# Приглашение «Это моя вечеринка»

Одностраничный сайт-приглашение: обложка → дресс-код → когда и где → анкета → подарок с видео.

## Что где лежит

| Путь | Что это |
|---|---|
| `dist/site/` | готовый сайт для хостинга: `index.html` + папка `assets/` |
| `dist/party-invite-site.zip` | тот же сайт архивом — для загрузки на хостинг |
| `dist/party-invite.html` | всё в одном файле (шрифты, фото, видео внутри, ≈ 8,6 МБ) — для просмотра без хостинга |
| `gas/Code.gs` | скрипт Google Таблицы, который принимает анкеты |
| `src/` | исходники: `index.html`, `style.css`, `app.js`, `silver.js` (шар, бахрома, дождь на WebGL) |
| `assets/` | фото, видео, картинка предпросмотра ссылки |
| `tools/build.mjs` | сборка |

## 1. Подключить Google Таблицу (5 минут, делает владелец таблицы)

Пока адрес таблицы не вписан, анкета работает в режиме показа: ответы никуда не уходят,
на экране «Спасибо» стоит пометка «Режим показа: адрес таблицы ещё не задан, ответы никуда не отправлены».

1. Создайте новую Google Таблицу (название любое, например «Вечеринка 12.12 — анкеты»).
2. Меню **Расширения → Apps Script**. Удалите содержимое открывшегося файла и вставьте целиком `gas/Code.gs`. Сохраните.
3. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит разрешение на доступ к таблице — разрешите.
   В таблице появится лист «Ответы» с заголовками: Получено, Изменено, Имя, десять вопросов, ID анкеты.
4. Кнопка **Начать развертывание → Новое развертывание**. Тип — **Веб-приложение**.
   «Выполнять как» — **Я**. «У кого есть доступ» — **Все**. Нажмите **Развернуть**.
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`). Откройте его в браузере — должно показать
   `{"ok":true,"message":"Приём анкет работает"}`.
6. Впишите адрес в страницу. В `src/index.html` найдите в блоке `window.PARTY` строку `endpoint: '',` и вставьте адрес в кавычки:
   `endpoint: 'https://script.google.com/macros/s/…/exec'`. Затем пересоберите (раздел 3).
   Без пересборки: ту же строку можно поправить прямо в `dist/site/index.html`.

Как это работает: каждая анкета — одна строка. Если гость нажал «Изменить ответы» и отправил снова,
обновляется его же строка (по «ID анкеты»), в столбце «Изменено» появляется время правки.
Текст, начинающийся с `=`, `+`, `-`, `@`, записывается как текст, а не как формула.

Если поменяли `Code.gs` после развёртывания: **Развертывание → Управление развертываниями → ✏️ → Версия: Новая → Развернуть**
(адрес остаётся прежним).

## 2. Выложить сайт

Сайт статический, подойдёт любой хостинг: загрузите содержимое `dist/site/` (или распакуйте `dist/party-invite-site.zip`)
в корень сайта. Нужен HTTPS — без него браузер телефона может не запустить видео со звуком.

Чтобы в мессенджере у ссылки была картинка, в `index.html` замените `content="assets/img/og.jpg"`
на полный адрес: `content="https://ваш-домен/assets/img/og.jpg"` (мессенджеры не понимают относительные адреса).

## 3. Пересобрать после правок

```
node tools/build.mjs --site dist/site
node tools/build.mjs --single dist/party-invite.html
```

Заменить видео: положите новый файл как `assets/video/gift.mp4` (H.264 + AAC, вертикальный, желательно до 10 МБ),
кадр-заставку — `assets/img/poster.jpg`, затем пересоберите.

Заменить тексты: `src/index.html`. Вопросы анкеты продублированы в `gas/Code.gs` (заголовки столбцов) —
меняйте в обоих местах; совпадение проверяет тест.

## 4. Проверки

```
node --test tests/gas.test.mjs                  # скрипт таблицы: 5 тестов
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist/site &
node tools/e2e.mjs http://127.0.0.1:8765/       # анкета от заполнения до финала, 8 шагов
node tools/shot.mjs http://127.0.0.1:8765/ shot.png --w 390 --h 844 --wait 7000   # снимок экрана
```

## Поведение, о котором полезно знать

- **Видео с подарком** запускается само, когда экран доходит до него. Браузер сам решает, разрешить ли звук:
  если запретил — видео идёт без звука и появляется кнопка «Смотреть со звуком».
- **Черновик анкеты** хранится в браузере гостя: закрыл страницу — ответы на месте.
- **«Меньше движения»** (настройка телефона): страница показывается сразу, без занавеса и анимаций появления.
- **Старый браузер без WebGL2**: шар, бахрома и дождь не рисуются, всё остальное работает.
- Библиотеки: GSAP 3.15 (ScrollTrigger, SplitText, CustomEase), Lenis 1.3 — лежат в `vendor/`, с интернета ничего не подгружается.
  Шрифты (Noto Serif Display, Great Vibes, Golos Text; лицензия OFL) — в `fonts/`.
